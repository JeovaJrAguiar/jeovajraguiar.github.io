Em Haskell, definimos funções de forma muito simples e elegante. Vamos criar as duas funções solicitadas:

[1.1] Assinatura de Função - Haskell Básico

Faça: a) uma função chamada dobro que recebe um parâmetro x e retorna o dobro de x; b) uma função soma3 que recebe três parâmetros a, b e c e retorna a soma deles.

Haskell 
-- 1.a - Função que retorna o dobro de um número
dobro :: Num a => a -> a
dobro x = x * 2

-- 1.b - Função que soma três números
soma3 :: Num a => a -> a -> a -> a
soma3 a b c = a + b + c
ghci> dobro 5
10
ghci> soma3 2 3 4
9
ghci> soma3 10 (-5) 7
12

🔍 Explicação do Código

Tipos: Num a => significa que 'a' pode ser qualquer tipo numérico (Int, Float, Double, etc.)

Função dobro: Recebe um parâmetro x e retorna x * 2

Função soma3: Recebe três parâmetros a b c e retorna sua soma

[1.2] Operadores Lógicos e Comparação

Usando os operadores lógicos ==, /=, >, <, >=, <=, faça as seguintes funções: a) ehZero, que retorna se um argumento n passado é zero; b) maiorQue10, que recebe um argumento n e retorna se ele é maior que 10; c) maiorQueX, que recebe um argumento n e um x e retorna se n é maior que x; d) sinalp, uma função que recebe um número n e retorna se ele é positivo.

Haskell 
-- 2.a - Verifica se o número é zero
ehZero :: Int -> Bool
ehZero n = n == 0

-- 2.b - Verifica se é maior que 10
maiorQue10 :: Integer -> Bool
maiorQue10 n = n > 10

-- 2.c - Compara se x é maior que y
maiorQueX :: Integer -> Integer -> Bool
maiorQueX x y = x > y

-- 2.d - Determina o sinal do número
sinalP :: (Num x, Ord x) => x -> String
sinalP x = if x > 0 then "positivo"
           else if x == 0 then "zero"
   else "negativo"
ghci> ehZero 0
True
ghci> maiorQue10 15
True
ghci> maiorQueX 5 3
True
ghci> sinalP (-5)
"negativo"

[1.3] Trabalhando com Tuplas

Faça: a) uma função somaPar que recebe um tupla de valores e retorna a soma; e uma função swap que recebe uma tupla de valores e retorna a tupla com ordem trocada.

Haskell 
-- 3.a - Soma elementos de uma tupla
somarPar :: Num x => (x, x) -> x
somarPar (x, y) = x + y

-- 3.b - Troca ordem dos elementos da tupla
swap :: (a, b) -> (b, a)
swap (a, b) = (b, a)
ghci> somarPar (3, 7)
10
ghci> swap (1, 2)
(2,1)
ghci> swap ("hello", 42)
(42,"hello")

[1.4] Funções com Múltiplos Retornos

Faça testes com as seguintes funções: div, mod, quot, rem e descubra o que elas fazem. Faça uma função chamada quocEResto que recebe dois valores x e y como argumento retorna uma tupla onde o primeiro valor é o quociente e o segundo o resto da divisão de x por y.

Haskell 
-- 4 - Retorna quociente e resto da divisão
quocEResto :: Integer -> Integer -> (Integer, Integer)
quocEResto x y = (quot x y, mod x y)
ghci> quocEResto 17 5
(3,2)
ghci> quocEResto 20 4
(5,0)

[1.5] Curry e Uncurry

Faça: 1. Uma versão curried da função soma chamada somaC que recebe dois argumentos x e y e retorna a soma deles; 2. Faça a versão uncurried da função soma chamada somaT que recebe uma tupla com dois elementos e retorna a soma deles; 3. Faça uma função chamada soma10, composta pela aplicação parcial da função somaC, que recebe um argumento x e retorna a soma de x + 10; 4. Faça uma função chamada somaC2 que é a versão curried de somaT, usando a função de base curry; 5. Faça uma função chamada somaT2 que é a versão uncurried do somaC, usando a função de base uncurry.

Haskell 
-- 5.1 - Versão curried da soma
somaC :: Num x => x -> x -> x
somaC x y = x + y

-- 5.2 - Versão uncurried da soma
somaT :: Num x => (x, x) -> x
somaT (x, y) = x + y

-- 5.3 - Aplicação parcial: soma com 10
soma10 :: Integer -> Integer
soma10 x = somaC x 10

-- 5.4 - Currying somaT com curry
somaC2 :: Num x => x -> x -> x
somaC2 = curry somaT

-- 5.5 - Uncurrying somaC com uncurry
somaT2 :: Num x => (x, x) -> x
somaT2 = uncurry somaC
ghci> somaC 3 7
10
ghci> somaT (3, 7)
10
ghci> soma10 5
15
ghci> somaC2 4 6
10
ghci> somaT2 (4, 6)
10

🎯 Conceitos Importantes

Currying: Transformar uma função que recebe uma tupla em uma função que recebe argumentos separados

Uncurrying: O processo inverso - transformar função curried em função que recebe tupla

Aplicação Parcial: soma10 é um exemplo de como criar funções especializadas
